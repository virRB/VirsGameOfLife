# VirsGameOfLife

## What is this?
This is my own take on [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life), with custom rules, roles, and emergent behavior.

## How to use
- Run the program
- Watch the simulation evolve in real time
- Type `/reset` to restart the simulation

## The system
- *Each cell has a state or class, with their own interaction rules*
  - Landlord (rich)
  - Robber (you get it 😏)
  - Guard (guy who protects the rich to get rich)
  - Scared (Enjoys chaos?)
  - Peace (The zen guy)
